## 2. Take the licence out of the creation agent's instructions

- [x] 2.1 Delete the clause in `RequisitionCreationSpecialist.ActionBlock` that conditions "say that no requisition draft is awaiting their confirmation" on the user's turn matching a confirmation shape *and* on the model holding none. It is a conditional whose antecedent is readable in the conversation and whose consequent is a fact only the application holds, with nothing in it telling the model to check the premise — which is why `gpt-5-mini` took the consequent 3 of 3 on turns the application had routed there *because* a draft existed
- [x] 2.2 Replace it with the rule in the same place and the same register: a turn that reads as an answer to a draft is answered by calling `confirm_requisition_draft` and reporting what it returns; that result is the only authority on whether a draft is waiting, in either direction; and a draft is presented only with the values the staging tool returned. The "in either direction" half matters — the forged probe is the same rule, and the correct answer there is the tool's own no-draft message

This is a fact about the system rather than advice: `CreateRequisitionAsync` already refuses without it, so no correct prose answer moves the state, and a turn that says "a draft is staged" in words has not moved anything
- [x] 2.4 Keep `Never assert a draft you have not staged` and its `fabricated fact` sentence untouched. They are a prohibition, not a licence, and `CreationStagingPromptTests` already guards them
